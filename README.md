## Core Components

### `ingest_to_chroma.py` — PDF → ChromaDB Ingestion

**Purpose:** Extract text from PDFs, chunk into clauses/sentences, embed with Hugging Face or BGE, store in ChromaDB.

**Usage:**

```bash
# Dry-run: Show what would be ingested without storing
python ingest_to_chroma.py --dry-run --limit 10

# Ingest 100 files
python ingest_to_chroma.py --limit 100

# Ingest all files (full ingestion)
python ingest_to_chroma.py

# Sample ingestion (first 5 files only, for quick testing)
python ingest_to_chroma.py --sample
```

**Configuration:**
- `SCHEME_DIR`: Path to PDF folder (default: `./saarthi_data/pdfs/notifications/`)
- `CHROMA_DIR`: Storage path for vector DB
- `BATCH_SIZE`: Chunks per batch (default: 64)
- `EMBED_MODE`: Auto-detected from env vars (`bge_api`, `hf`, or `dummy` for testing)

**Output:**
- Prints `"processed N/M files"` every 50 files
- Final summary: `"Total chunks prepared: <count>"`

### `chunker.py` — Text Segmentation

**Function:** `chunk_text(text: str, max_tokens: int = 400, overlap_words: int = 50) → List[str]`

**Strategy:**
- Splits on clause boundaries (`.`, `!`, `?`, `;`)
- Targets ~300–500 tokens per chunk
- Overlaps consecutive chunks by 50 words to preserve context

**Example:**
```python
from chunker import chunk_text
chunks = chunk_text("Detailed document text...", max_tokens=400)
```

### `embeddings_wrapper.py` — Embedder Abstraction

**Class:** `Embedder()`

**Methods:**
- `get_embeddings(texts: List[str]) → List[List[float]]`: Returns embedding vectors

**Modes (auto-detected):**
1. **BGE API** (production): Requires `BGE_API_URL` + `BGE_API_KEY`; calls external BGE service for `bge-large-en` embeddings
2. **Hugging Face** (fallback): Uses sentence-transformers locally; model from `HF_EMBED_MODEL` env var (default: `all-MiniLM-L6-v2`)
3. **Dummy** (testing): Returns random vectors; useful for dry-runs without real embeddings

**Example:**
```python
from embeddings_wrapper import Embedder
embedder = Embedder()
vecs = embedder.get_embeddings(["Hello world", "Foo bar"])
# Returns list of 2 embedding vectors
```

## Performance & Tuning

### Embeddings

- **Hugging Face (HF):** Fast, local, ~384-dim vectors. Good for quick prototyping.
- **BGE API:** Higher quality, production-grade, requires API credentials. ~1024-dim vectors.
- **Batch size:** Default 64 chunks per write to ChromaDB. Adjust in `ingest_to_chroma.py` if OOM errors.

### Chunking

- Default: max 400 tokens, 50-word overlap
- Adjust in `ingest_to_chroma.py` config or via `chunker.py` parameters
- Smaller chunks (200–300 tokens) → more precise retrieval, larger DB
- Larger chunks (500–600 tokens) → faster ingestion, less precision

### ChromaDB

- **Backend:** DuckDB + Parquet persistence
- **Storage:** `chroma_db/` directory (default ~2–5 GB for full corpus with 384-dim embeddings)
- **Performance:** In-memory querying after initial load; suitable for up to ~100k chunks

## Troubleshooting

### Issue: "No /Root object! - Is this really a PDF?"

**Cause:** Some downloaded scheme PDFs are malformed or HTML-wrapped.

**Solution:**
1. Re-download from source (manual or updated scraper)
2. Convert via online PDF tools (e.g., CloudConvert)
3. Implement OCR fallback in `ingest_to_chroma.py` using `pdf2image` + `pytesseract`

**To enable OCR (optional):**
```bash
pip install pdf2image pytesseract
# Ensure tesseract-ocr is installed: brew install tesseract (macOS)
```

Then uncomment OCR fallback in `ingest_to_chroma.py`:
```python
# In ingest_to_chroma.py, around line 85:
# if not text and "No /Root object" in str(e):
#     text = extract_via_ocr(pdf_path)
```

### Issue: Embeddings taking too long

**Cause:** Using HF with large model or many chunks.

**Solution:**
- Use smaller HF model: `export HF_EMBED_MODEL="all-MiniLM-L6-v2"` (fastest)
- Or provide BGE API key for production-grade speed + quality

### Issue: ChromaDB connection errors

**Cause:** Corrupted or incompatible DB version.

**Solution:**
```bash
# Backup and reset:
mv chroma_db chroma_db.bak
python ingest_to_chroma.py --sample  # Re-ingest
```

## Advanced: Integration with LLM

### Example: RAG QA System

```python
from test_retrieval import retrieve_chunks
import requests  # or use OpenAI, Anthropic, etc.

def answer_question(query: str):
    # Retrieve context
    results = retrieve_chunks(query, k=5)
    chunks = results['documents'][0]
    context = "\n".join(chunks)
    
    # Call LLM
    response = requests.post("http://localhost:8000/v1/completions", json={
        "prompt": f"Context:\n{context}\n\nQuestion: {query}\nAnswer:",
        "max_tokens": 200
    })
    return response.json()['choices'][0]['text']

# Usage
answer = answer_question("What is Sukanya Samriddhi Yojana?")
print(answer)
```
